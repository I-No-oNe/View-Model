# Deprecated Versions

> [!NOTE]
> This branch contains older versions of the `view-model` library that are now **deprecated** and **no longer supported**.
> In the interest of maintaining open-source transparency and ensuring that legacy projects remain buildable, these versions have been archived here. Please note that other branches officially supports only the **two most recent releases of Minecraft**.

-----

### Why this branch exists?

While I recommend all users upgrade to the latest version for performance improvements, bug fixes, new features and more, this archive is provided for:

  * **Legacy Support:** Users which prefer older Minecraft versions.
  * **Code Reference:** Developers looking to see how specific features were implemented in previous iterations.
  * **Security:** Ensuring that the original source code remains available and untampered with for existing builds.
